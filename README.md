# InAmigos Foundation Website

A responsive NGO website developed using HTML, CSS, and JavaScript for InAmigos Foundation. The website showcases the organization's mission, initiatives, social impact, volunteer opportunities, donation support, and community outreach programs.

## Features

* Responsive and modern user interface
* About Us section with NGO information
* Mission and Vision statements
* Certifications and Recognition section
* Initiative showcase (SEVA, Bachpanshala, Jeev, Udaan, Prakriti, Vikas)
* Impact statistics and achievements
* Gallery showcasing community activities
* Donation support section
* Volunteer registration form
* Footer with organization information

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Sections Included

* Home
* About
* Gallery
* Initiatives
* Impact
* Contact / Donate
* Volunteer

## Purpose

This project was developed as part of a web development internship assignment to demonstrate front-end development skills using HTML, CSS, and JavaScript while creating a professional NGO website experience.
